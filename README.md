# 🧪 C# — Primeiros Passos: Variáveis e Tipos

> Programa console em C# explorando os tipos primitivos da linguagem através de um personagem RPG.

## 👥 Desenvolvedor

- Hootsuki 🌙

---

## 📖 Sobre o Projeto

Este é o ponto de partida de uma jornada em C#.

O programa declara variáveis dos principais tipos primitivos da linguagem — `string`, `int`, `float` e `bool` — e as exibe no console utilizando **interpolação de strings** (`$"..."`), um recurso moderno e essencial do C#.

Os dados representam um personagem de RPG chamado **Hootsuki**, com nome, nível, vida e status de sobrevivência.

---

## 🖥️ Saída Esperada

```
Nome: Hootsuki
Nivel: 10
Vida: 100,0
Vivo: True
```

---

## 🧠 Conceitos Praticados

| Conceito | Descrição |
|---|---|
| `string` | Cadeia de caracteres — armazena texto |
| `int` | Número inteiro — sem casas decimais |
| `float` | Número de ponto flutuante — com casas decimais |
| `bool` | Booleano — `true` ou `false` |
| `Console.WriteLine()` | Imprime uma linha no terminal |
| Interpolação `$"..."` | Insere variáveis diretamente em strings |
| Formatador `:F1` | Exibe float com 1 casa decimal |

---

## ⚙️ Como Executar

**Pré-requisitos:** [.NET SDK](https://dotnet.microsoft.com/download) instalado.

Compile e execute com:

```bash
dotnet run
```

Ou, se preferir compilar manualmente:

```bash
dotnet build
dotnet run --project .
```
